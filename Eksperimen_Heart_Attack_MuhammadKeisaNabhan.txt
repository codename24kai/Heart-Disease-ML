=========================================================
EKSPERIMEN SISTEM MACHINE LEARNING
=========================================================

Nama Proyek
-----------
Heart Disease Prediction

Dataset
-------
Heart Disease Cleveland Dataset

Tujuan
------
Membangun model Machine Learning untuk memprediksi apakah seorang pasien memiliki penyakit jantung berdasarkan data klinis yang tersedia.

=========================================================
1. Data Preparation
=========================================================

Tahapan preprocessing yang dilakukan meliputi:

- Memuat dataset.
- Menghapus data duplikat.
- Menangani missing value.
- Memisahkan fitur dan target.
- Membagi dataset menjadi data training dan data testing.
- Melakukan normalisasi fitur menggunakan StandardScaler.
- Menyimpan scaler untuk proses inference.

=========================================================
2. Eksperimen Model
=========================================================

Beberapa algoritma Machine Learning diuji untuk memperoleh performa terbaik, antara lain:

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine
- K-Nearest Neighbor

Seluruh model dievaluasi menggunakan metrik:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

=========================================================
3. Hyperparameter Tuning
=========================================================

Model terbaik kemudian dilakukan optimasi menggunakan GridSearchCV untuk memperoleh kombinasi hyperparameter yang menghasilkan performa paling optimal.

=========================================================
4. Model Terbaik
=========================================================

Model dengan performa evaluasi terbaik dipilih sebagai model final.

Model tersebut kemudian disimpan sebagai:

artifacts/models/best_model.pkl

Sedangkan objek preprocessing disimpan sebagai:

preprocessing/scaler.pkl

=========================================================
5. Experiment Tracking
=========================================================

Seluruh proses eksperimen dicatat menggunakan MLflow, meliputi:

- Parameter model
- Metrics evaluasi
- Model
- Artifact
- Signature model

=========================================================
6. Model Serving
=========================================================

Model di-deploy menggunakan FastAPI.

Endpoint utama:

POST /predict

Endpoint monitoring:

GET /metrics

=========================================================
7. Monitoring
=========================================================

Monitoring dilakukan menggunakan Prometheus dan Grafana.

Metrik yang dimonitor antara lain:

- Total Prediction Requests
- Positive Prediction
- Negative Prediction
- Average Prediction Latency

=========================================================
8. Continuous Integration
=========================================================

Repository telah dikonfigurasi menggunakan GitHub Actions.

Workflow dijalankan otomatis ketika terjadi:

- Push ke branch main
- Pull Request ke branch main

Tahapan workflow:

1. Checkout repository
2. Setup Python 3.13
3. Install dependency
4. Menjalankan preprocessing
5. Training model
6. Hyperparameter tuning

=========================================================
9. Kesimpulan
=========================================================

Berdasarkan seluruh eksperimen yang dilakukan, diperoleh model Machine Learning dengan performa terbaik yang kemudian digunakan untuk proses deployment, monitoring, dan inference. Seluruh pipeline telah dilengkapi dengan experiment tracking menggunakan MLflow, monitoring menggunakan Prometheus dan Grafana, serta otomatisasi pipeline melalui GitHub Actions.
